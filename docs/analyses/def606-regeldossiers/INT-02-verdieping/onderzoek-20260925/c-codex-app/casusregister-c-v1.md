# Casusregister C — INT-02 — v1

25 september 2026. Onafhankelijke eerste versie. Normvoorstel **INT02-C-N1** in `onderzoek-c-v1.md` §Q1; geen vastgesteld nieuw beleid. Alle inhoudelijke verwachtingen hieronder gelden uitsluitend voor INT-02, niet als integraal definitieoordeel. Synthetische rechtsvoorbeelden zijn geen weergave van actueel recht. **Elke rij geldt tweemaal:** als door de generator geleverde kandidaat en als aangeleverde inhoud. T moet bij dezelfde tekst, betekenis en bewijs dezelfde uitkomst geven. Alleen G/H mag een afzonderlijk nieuw voorstel opleveren; T overschrijft nooit invoer.

Afkortingen: V = voldoet; VN = voldoet niet; O = inhoudelijk open/onvoldoende informatie; NB = niet uitgevoerd wegens ontbrekend toetsobject of verplichte invoer; RR = actuele automatische `review_required`, nog geen inhoudelijk oordeel. Onder voorkeursoptie O1 volgt V/VN pas uit menselijke beoordeling. H is een inactief ontwerp: op verzoek maximaal één voorstel, geen automatische activatie onder DEF-638. Grond A = meegeleverde ASTRA-teksten; B = besluiten (geen totaalscore, contextplicht); C = expliciete synthetische bedoeling; H0 = historisch bewijs d68a98a9 met actuele broncontrole. P1–P6 zijn de uitgevoerde proeven in `bewijs/proefuitkomsten-v1.json`.

De actuele runtime-verwachtingen voor P1–P6 zijn vóór uitvoering bewaard in `bewijs/proefopzet-v1.json`. De overige G/T/H-rijen zijn acceptatieontwerp; er zijn geen achteraf passend gemaakte modeluitkomsten. C01–C06 houden hun originele tekst en scenario. Nieuwe scenario's liggen binnen C100–C129.
